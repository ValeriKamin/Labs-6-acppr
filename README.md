# Практична робота №6  
## Розв’язання задачі про призначення

Програма реалізує розв’язання задачі про призначення двома методами:

- угорським методом;
- симплекс-методом.

## Можливості програми

- введення матриці вартостей вручну;
- завантаження готового варіанту;
- побудова матриці призначень;
- пошук оптимального розв’язку;
- обчислення загальної вартості робіт;
- формування протоколу обчислень.

## Технології

- C#
- .NET
- Console Application
- Visual Studio
